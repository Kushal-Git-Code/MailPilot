- Windows gotcha hit during Step 11 testing: stopping a `npm run dev` background task (via `TaskStop`) doesn't always kill the underlying `node.exe` child process — it can stay bound to its port after the wrapper task is gone. This caused a confusing "unstyled page" bug that was actually a browser hitting a stale orphaned server on an old port, not a real CSS issue. If a dev server behaves unexpectedly after being "stopped," check `Get-NetTCPConnection -LocalPort 3000,3001,... -State Listen` for leftover `node.exe` processes before assuming it's a code bug.
